# Non-stationary spatial modelling of monsoon rainfall extremes

Code and intermediate results for a non-stationary spatial extreme-value analysis
of monsoon-season maximum daily rainfall over Himachal Pradesh and Uttarakhand,
north-west Himalaya.

The analysis fits a generalised extreme value distribution whose location and
scale vary smoothly in space, with a Gaussian copula whose correlation range
depends on elevation, to **208 ERA5 grid cells × 41 monsoon seasons (1984–2024)**.
All numerical results reported from the analysis can be generated by the workflows in this repository.

---

## Pipeline

The pipeline has two preparation steps followed by four analysis workflows.

```
  GRIB (ERA5 hourly)
        │   era5_data_processing_extremes_analysis_corrected.ipynb
        ▼
  ERA5_daily_IST_HP_UK.parquet          daily, JJAS, 208 cells
        │   preprocess.r
        ▼
  ams_with_covariates.csv               8,528 cell-seasons × 34 columns
        │   preliminary.r · fit_and_gof.r · bootstrap.r · bootstrap_validation.r
        ▼
  outputs/                              28 tables and logs
```

| file | stage | reproduces | runtime |
|---|---|---|---|
| `era5_data_processing_extremes_analysis_corrected.ipynb` | hourly → daily | the analysis dataset itself | ~20 min |
| `preprocess.r` | daily → cell-seasons | the block maxima and every covariate | ~10 s |
| `preliminary.r` | analysis | Table 1, grid climatology, per-cell Mann–Kendall tests | ~10 s |
| `fit_and_gof.r` | analysis | the fitted model, every goodness-of-fit number, the hazard products | ~8 min |
| `bootstrap.r` | analysis | every season-block bootstrap interval computed on ERA5 alone | ~13 min |
| `bootstrap_validation.r` | analysis | the three-product reproducibility bootstrap and elevation-band ratios | ~11 min |

The four analysis scripts are mutually independent and can run in any order, or in
parallel. Runtimes are for 8 cores.

### Requirements

**R 4.3** with `evgam` 1.0.2, `arrow`, `dplyr`, `tidyr`, `sf`, `ggplot2`, `scico`.
`evgam` does the penalised GEV fitting; everything else is data handling and
plotting.

**Python 3.12** for the notebook, with `xarray`, `cfgrib`, `rioxarray`,
`rasterio`, `geopandas`, `pyarrow`, `pandas`, `numpy`. `dask` is optional —
without it the hourly fields are loaded eagerly, which needs more memory.

### Data not included here

The repository holds code, not the source
data. To rebuild from scratch you need:

- **ERA5 hourly single-level fields** over 75–81.5°E, 28–33.5°N, June–September
  1984–2024: total precipitation, 2 m temperature, 2 m dewpoint, surface
  pressure, 10 m wind components. From the Copernicus Climate Data Store.
- **A SRTM mosaic** covering the domain.
- **Indian state boundaries**, for clipping and for the maps.
- For the validation script only: **IMD gridded rainfall** (0.25°) and **GPM
  IMERG**, both on the common 2000–2024 window.

## What the model is

**Margins.** A GEV fitted to the 41 seasonal maxima at each of the 208 cells
simultaneously, with

- location `μ(s, t)` = a penalised thin-plate spline over space, `k = 70`, plus a
  single linear term in season,
- log scale `σ(s)` = a penalised thin-plate spline over space, `k = 20`,
- shape `ξ` = **one constant for the whole domain**.

Fitted in kilometres, not degrees: a degree of longitude spans about 0.86 of a
degree of latitude at this latitude, so an isotropic spline in degrees would make
the smoothing anisotropic.

**Dependence.** A Gaussian copula on the normal scores, with a Paciorek–Schervish
non-stationary Matérn correlation (ν = ½) whose range depends on elevation,

```
ρᵢ = ρ₀ · exp(γ eᵢ)
```

`eᵢ` is standardised cell elevation. Fitted by pairwise composite likelihood over
all cell pairs.

**Uncertainty.** A season-block bootstrap that resamples whole seasons with
replacement and refits **both** stages on each replicate, so dependence between
cells is carried through into every interval.

### Main Results

| quantity | estimate | 95% interval |
|---|---|---|
| shape ξ | 0.092 | [0.040, 0.140] |
| trend β | +0.158 mm per season | [−0.037, +0.350] |
| correlation range ρ₀ | 126 km | [96, 156] |
| elevation effect e^γ | 1.53 per SD of elevation | [1.32, 1.76] |
| design effect | 52.2 | [39.8, 63.3] |
| 100-year return level | 50–453 mm across the domain | — |
